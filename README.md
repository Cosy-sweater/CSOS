# CSOS - Console Simulated Operating System

## Описание проекта
Данный проект является учебным заданием курса "конфигурационного управления", в рамках которого
разрабатывается эмулятора для языка оболочки ОС. Работа эмулятора должна быть приближена к работе
в командной строке UNIX-подобной ОС. Эмулятор выполнен в командной строке в виде CLI приложения.

## Функции проекта
Поддерживаются команды:
- заглушки ls и cd, выводящие свое имя и аргументы
- exit для завершения работы программы

Также присутствует вывод ошибки при обработке неизвестных команд

## Запуск и использование приложения
Для запуска необходимо установить интерпретатор Python. 
Приложение запускается внутри среды разработки Python или внутри командной строки с использованием команды ```py .src/main.py```.

## Примеры использования
1. Написать команду ls
2. Написать команду cd
